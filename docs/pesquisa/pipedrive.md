# Pipedrive — Referência de produto

> Pesquisa competitiva para inspirar um CRM de vendas focado em **revisional de juros abusivos** (veículos, imóveis e empréstimo pessoal), com captação via Meta Ads e Google Ads.  
> Fonte: [pipedrive.com/pt](https://www.pipedrive.com/pt) · Relatório sintetizado em ago/2026.

---

## Posicionamento

O Pipedrive é o CRM de **funil visual (kanban)** mais associado a “fechar negócios com clareza”: atividade → deal → fechamento — sem pretender ser suite de marketing all-in-one.

- Escala: **+100.000 empresas** em **179 países**
- Brasil: um dos 4 maiores mercados; site e suporte em PT-BR
- Origem: Tallinn (2010); HQ NY; forte penetração SMB
- Promessa: visualizar o funil, automatizar follow-ups, IA para e-mail/relatórios, marketplace 500+

**Para revisional:** o job to be done é **não deixar lead esfriar** e **ver gargalos do funil** — exatamente o que operações de Meta/Google + closers precisam no comercial pré-contrato. Os gaps nativos (WhatsApp BR, ads, honorários, ICP-Brasil, OAB) são a oportunidade de verticalização.

## ICP

| Dimensão | Perfil |
|----------|--------|
| Porte | SMB / PME — solo sellers a times de 5–50 |
| Função | Times de vendas / receita |
| Dor | Planilha ou CRM complexo → baixa adoção; falta de follow-up |
| Fit forte | Processo comercial claro, ciclo curto/médio, vários deals paralelos |
| Fit fraco | Marketing automation pesado, enterprise pesado, vertical jurídica nativa |

**Analogia revisional:** escritórios/empresas de revisão com SDR/closer, mídia paga e volume alto — não o advogado solo sem processo comercial.

---

## Fluxo de negócio modelado

```
Captura (form / chat / ads / Zapier)
 → Caixa de entrada de Leads (quente / morno / frio)
 → Deal no Funil (kanban por etapas)
 → Atividades obrigatórias (ligar, e-mail, reunião, WhatsApp*)
 → Automações (tarefa, mover etapa, sequência)
 → Proposta / contrato (Smart Docs / PandaDoc)
 → Won / Lost (+ motivo de perda)
 → Projects (pós-venda) [opcional]
```

\*WhatsApp via marketplace/terceiros — não nativo oficial BR.

**Insight de UX:** o Pipedrive força **próxima ação** em todo deal — “atividade-first”, não só status.

## Stack e plataforma (público)

- Cloud SaaS (AWS EU/US) · web + mobile
- API REST aberta; Messaging App Extension para WhatsApp/Messenger
- Segurança: SOC 2/3, ISO 27001/27701, GDPR, EU-US Data Privacy Framework
- Controles: 2FA, SSO, visibility groups, IP/time rules (Ultimate reforçado)

**Gap BR:** compliance global forte ≠ LGPD operacional setorial + normas OAB (sigilo, publicidade, dados sensíveis de crédito).

## Insights para CRM de revisional

### O que copiar da UX

| Padrão Pipedrive | Aplicação revisional |
|------------------|----------------------|
| Kanban por etapas | Lead Ads → Qualificação → Docs → Análise → Proposta → Contrato → Protocolo → Acompanhamento |
| Atividade obrigatória | Todo card com próximo contato (WA/ligação) em SLA de minutos |
| Inbox de leads pré-funil | Separar lead frio de deal; scoring por tipo (veículo/imóvel/EP) |
| Multi-funis | Comercial vs operacional/processual |
| Motivo de perda | Sem abusividade, concorrente, sem docs, desistiu → feedback para Ads |
| Roteamento | Round-robin por campanha / região / tipo de dívida |
| Campos custom + fórmulas | Taxa, saldo, banco, % honorários, ticket estimado |
| Tracking de engajamento | Abrir proposta / clicar link de assinatura |
| Trial PLG + template de funil | Pipeline “Revisional” no dia 1 |

### Gaps nativos = oportunidade

| Gap | Por que importa |
|-----|-----------------|
| Proposta de honorários + cálculo êxito/% | Smart Docs é genérico B2B |
| Assinatura ICP-Brasil / gov.br | eSignature global ≠ fluxo advocatício BR |
| WhatsApp oficial (WABA) first-class | Canal #1 de conversão de lead Meta no BR |
| Meta/Google Ads nativos (CAPI, offline conversions) | Atribuição frágil via middleware |
| Compliance OAB | Publicidade, captação, sigilo, dados de crédito |
| LGPD operacional setorial | Consentimento, retenção de docs bancários |
| Workflow jurídico | Petição, protocolo, prazos — Projects é genérico |
| Checklist documental consumer | Extrato, contrato, CNH sem UX de coleta |
| Cobrança em BRL / NF-e | Pipedrive cobra USD |
| IA de triagem jurídica | Elegibilidade / abusividade além de “escrever e-mail” |

### Posicionamento sugerido vs Pipedrive
> **“Pipedrive do comercial jurídico de revisional”**: mesma clareza de funil + atividades, mas com **WhatsApp oficial, leads Meta/Google nativos, honorários + assinatura BR e compliance OAB** embutidos — onde o Pipedrive para na cola do marketplace.

### Prioridade de features
1. Funil kanban + SLA de 1ª resposta  
2. Inbox WhatsApp + atribuição de lead Ads  
3. Checklist docs + status  
4. Proposta/honorários + assinatura  
5. Motivos de perda → painel de mídia  
6. Funil 2: acompanhamento do caso pós-contrato  

### Tese em uma frase
Pipedrive prova que **funil visual + próxima atividade + trial sem fricção** vencem adoção em SMB. Para revisional, copie essa UX comercial e ganhe nos gaps: **WhatsApp BR, ads nativos, honorários/assinatura e compliance jurídico**.
